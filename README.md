## Запуск

Нужен Python 3.10 или новее. Сторонние библиотеки и дополнительные сервисы
не нужны. Выполняйте команды из корня репозитория:

```bash
python3 lab4.py
```

Программа демонстрирует все пять заданий: выводит чётные числа
`[-2, 0, 2, 4, 6]`, факториал `120`, сумму `7` с записью вызова в журнал,
два результата `36` при одном фактическом вычислении и три приветствия.
Журнал выводится в stderr, остальные результаты — в stdout, поэтому порядок
их отображения при перенаправлении потоков может отличаться.

## Особенности реализации

- `filter_even` принимает и списки, и другие итерируемые последовательности
  целых чисел. Возвращает новый список, не меняя исходный.
- `factorial(0)` возвращает `1`. Отрицательные аргументы вызывают `ValueError`,
  нецелые числа и `bool` — `TypeError`.
- `log_calls` записывает имя и аргументы до вызова, возвращает результат
  функции и не подавляет исключения. Для просмотра журнала при импорте модуля
  настройте `logging.basicConfig(level=logging.INFO)` в своей программе.
- `memoize` предназначен для чистых функций с хешируемыми аргументами.
  Кэш не ограничен по размеру и действует до завершения процесса. Порядок
  именованных аргументов не важен; `f(1)` и `f(x=1)` имеют разные ключи.
  Исключения не кэшируются. Аргументы с равными значениями и хешами могут
  использовать одну запись, поэтому функция не должна различать их по типу.
- `repeat` принимает положительное целое число, повторяет вызов с теми же
  аргументами и возвращает последний результат. При исключении прекращает
  повторы. Повторяются и побочные эффекты функции.
- Все декораторы сохраняют имя, документацию и ссылку `__wrapped__` благодаря
  `functools.wraps`.
